# /crear-canal

**Qué hace:** crea un canal de texto o voz dentro de una categoría existente. Le aplica el prefijo visual `🧩│` y hereda los permisos de la categoría.

**Uso:** `/crear-canal nombre:<nombre> categoria:<categoría> tipo:<texto|voz>`

**Ejemplo:** `/crear-canal nombre:clips categoria:CONTENIDO tipo:texto` crea `🧩│clips` dentro de `🎬 CONTENIDO`.

**Limitaciones:** solo puede usarlo `OWNER_USER_ID`. No duplica un canal con el mismo nombre final. El bot necesita Administrador o Gestionar canales.
