# /proximo

**Qué hace:** presenta automáticamente la primera publicación futura del calendario.

**Uso:** `/proximo`

**Ejemplo:** `📅 Próximo vídeo · 11/09/2026 · 20:30`.

**Limitaciones:** lee `programacion.json`; al terminar el calendario debes añadir las siguientes publicaciones. Como alternativa admite `NEXT_VIDEO_AT` en `.env`, con formato `AAAA-MM-DDTHH:MM`.
