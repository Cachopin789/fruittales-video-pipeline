# /crear-rol

**Qué hace:** crea un rol de Discord con el nombre y color que indiques.

**Uso:** `/crear-rol nombre:<nombre> color:<#RRGGBB o nombre>`

**Ejemplo:** `/crear-rol nombre:Editor color:#3498DB` crea el rol `Editor` en azul.

**Limitaciones:** solo puede usarlo `OWNER_USER_ID`; no duplica roles existentes. Acepta `#RRGGBB` o rojo, verde, azul, amarillo, naranja, morado, rosa y gris. El rol del bot debe estar por encima de los roles que vaya a gestionar.
