# /crear-invitacion

**Qué hace:** genera una invitación temporal y privada para el servidor.

**Uso:** `/crear-invitacion duracion_horas:<1-168> usos_maximos:<0-100>`

**Ejemplo:** `/crear-invitacion duracion_horas:24 usos_maximos:5` crea un enlace válido 24 horas y para cinco usos.

**Limitaciones:** solo puede usarlo `OWNER_USER_ID` y desde un canal de texto. Usa `0` como usos máximos para no limitar la cantidad. El bot necesita el permiso **Crear invitación**.
